Get Started in Seconds

One command to install, one command to scan

# Install Iris
$ curl -sSL https://pixelcity.dev/iris/install.sh | sh

# Scan your project
$ iris scan . --scanner sast,sca,secrets

# Output to SARIF for GitHub
$ iris scan . --format sarif --output results.sarif

# Filter by severity
$ iris scan . --severity critical,high
