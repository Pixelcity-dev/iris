Install Iris

Iris is an open-source security scanner for source code, dependencies, infrastructure, containers, and websites. The CLI supports structured reports for local review and CI pipelines.

Quick Install (Recommended)

curl -fsSL https://cdn.pixelcity.dev/iris/install.sh | sh # also: https://cdn.pixelcity.top/iris/install.sh # also: https://pixelcity.top/iris/install.sh
