What does Iris do? (In simple words)

Imagine you wrote a website or an app. Iris is like a security inspector that looks at your work and tells you: "Hey, you left a door unlocked here", "This password is visible", "This website setting is not safe". It checks your code (like a spellchecker for security) and your live website (like testing if your doors and windows are locked).

Quick Start — Your first check in 30 seconds

After installing, try these. Each one takes seconds.

1. Check your code (your current folder)

Iris looks at all your files and tells you if there are secrets, bugs, or risky settings.

iris scan .

You will see: OK No issues or a list like [MEDIUM] Cookie without Secure with a fix.

2. Check a website (any website)

Iris visits the website and checks 20+ security settings.

iris webscan https://example.com

Try with your own site: iris webscan https://pixelcity.top

3. Save a report to share

Get a nice HTML report you can send to your team or boss.

iris scan . --format html --output report.html # then open report.html in your browser

WebScan — Deep website check

Just give us a URL, we check 20+ things. In simple words:

Basic Safety

Headers: Are your security headers set? (like HSTS, CSP)
TLS: Is your HTTPS certificate OK? Not expired?
Cookies: Are your cookies set safely?
HTTPS Redirect: Does http jump to https?

Information

Disclosure: Are you leaking server info?
CORS: Can any website read your data?
Clickjacking: Can someone put your site in a fake frame?
SRI: Are your scripts protected?

Hidden Files

Exposed Files: Is /.env or /.git visible? (very bad!)
Directory Listing: Can people see your file list?
Security.txt: Do you have a way for hackers to contact you?

Attacks (safe tests)

Open Redirect: Can someone redirect your users to evil.com?
XSS: Can someone inject code into your page?
SQLi: Does your site show database errors?
All tests are safe — we don't harm your site.

iris webscan https://pixelcity.top --severity medium iris webscan https://example.com --format sarif --output ws.sarif
Example result for pixelcity.top: 7 small issues found (Medium:1 Low:5 Info:1) — like missing COOP headers, Via disclosure. No critical problems. OK Good!

Understanding your results

Iris shows you a list. Here's how to read it:

Severity (how bad?)

CRITICAL Fix today! Hackers can get in.
HIGH Fix this week.
MEDIUM Fix soon.
LOW Good to fix, not urgent.
INFO Just information.

What to do?

Each finding has:
• Title — what is wrong
• Description — where it is
• Fix — how to fix it (in green)
• Rule — technical ID
Just follow the Fix line. If you use --format html, you get a nice report with a risk score and compliance mapping.

Risk Score (simple)

Iris gives you a number: Critical=40 points, High=10, Medium=3, Low=1. Total: 0 = Excellent, <5 = Low, <20 = Medium, <50 = High, 50+ = Critical. For pixelcity.top, score is 8 → Medium (good!).

Configuration — For advanced users (optional)

You don't need this, Iris works without it. But if you want to customize:

iris init # creates .iris.yaml — edit it if you want
version: "1.1.0" scanners: { sast: true, sca: true, secrets: true, iac: true, container: true, dast: true, webscan: true, network: true, license: true } report: { format: html, color: true } filter: min_severity: low exclude_rules: [webscan-missing-security-txt] # hide this rule if you don't care

You can also use --severity high or --profile enterprise directly in the command without a file.

FAQ — Common Questions

Do I need to know a lot about security?

No! Just run iris scan . and read the Fix lines. They tell you exactly what to do. Use --format html for a nice report.

Does it work for my website, even if it's not code?

Yes! iris webscan https://your-site.com works for any website — shop, blog, app, API. Just give it the URL.

Does it work with my programming language?

Almost certainly yes. We support 11+ languages: Go, Java, JavaScript, TypeScript, Python, Rust, PHP, Ruby, C/C++, C#, Kotlin, Swift — and 11 package systems.

I see a lot of LOW/INFO findings. Should I worry?

No. Focus on CRITICAL and HIGH first. LOW/INFO are like "you could improve this" — fix them when you have time.

Is it safe? Will it hack my site?

Yes, safe. All website checks are read-only (just GET requests). We don't delete or change anything. We use safe payloads like irisXSS1337.

Do I need to install anything else?

No. One file, no dependencies. Works offline after install. Docker also available.
